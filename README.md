# Imperium

Open-sourced on a whim. You can join the discord [here](https://discord.com/invite/fzvzYJCSjz). I likely won't be maintaining Imperium on Roblox in the future.

[The classic Monopoly experience, now in Roblox](https://www.roblox.com/games/110109018598423/Imperium)! Will you prosper, or will you be drained by the great big capitalist machine? Refer to Monopoly rules for how to play.

Best played on desktop or mobile, however console is also supported.
